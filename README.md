## Project Description
FINGERS++ is a revolutionary, physics-driven web application that visualizes base-5 mathematical computations using interactable, floating digital hands. It replaces boring integers with a highly dynamic, zero-gravity physics sandbox complete with procedurally generated audio, physics-based dragging, and cinematic Thanos snaps for subtraction.

## The Problem (that doesn't exist)
Modern society has become dangerously reliant on abstract Arabic numerals (0-9). As a species, we have forgotten our biological roots: counting on our fingers. Worse yet, when the numbers get too big, we simply run out of hands, leading to global economic instability and mild embarrassment at the grocery store checkout lines. 

## The Solution (that nobody asked for)
FINGERS++ shatters the biological ceiling by rendering up to 1,000 disembodied hands in a zero-gravity vacuum. We've replaced standard calculators with a dynamic physics sandbox where every calculation literally spawns, flings, or Thanos-snaps hands out of existence. Need to represent decimals? Our integrated "Gore Mode" spawns fractional blood droplets scaled perfectly to their floating-point value. Math has never been more visceral, violent, or physically accurate!

## Technical Details

### Technologies/Components Used

**For Software:**
- **Languages used:** JavaScript (ES6+), HTML5, CSS3
- **Frameworks used:** React.js (Vite)
- **Libraries used:** Matter.js (2D Rigid Body Physics Engine), Tailwind CSS (Styling), Web Audio API (Procedural Audio Synthesis)
- **Tools used:** Node.js, npm, Git

**For Hardware:**
- **Main components:** N/A (Software-only project)
- **Specifications:** Any modern web browser capable of running HTML5 Canvas and the Web Audio API. 
- **Tools required:** A mouse (to ruthlessly fling the hands) and a keyboard (to type math).
